涨停复盘 · 2026-10-28（周三）

对比基准：2026-10-27（周二）｜口径：沪深两市（不含北交所）｜数据源：同花顺涨停池 / 概念板块 + 东方财富涨停·炸板·跌停池 + 腾讯行情快照｜配色规则：红＝情绪正面（涨停家数增、封板率升），绿＝情绪负面（炸板增、跌停增、封板率降）——跌停家数是反向指标，增加标绿

一句话结论：放量普涨回来了，"封得住"没回来 —— 参与度一夜翻倍、封板率跌到建报以来最低 50.0%，涨停扩张全靠分母撑起来。 涨停 41 → 69 家（+28 / +68%）、炸板 28 → 69 只（+41）、封板率 59.4% → 50.0%（-9.4pct）、跌停 21 → 3 家（封死率 75.0% → 16.7%）； 两市成交 14610 → 16285 亿（+11.5%），11 个指数全部收红、成交额环比全部为正（8.6% ~ 18.5%）。 量价同向放大 = 增量入场，这一点与 10-08 / 10-22 的「全线放量 + 全线下跌」性质完全相反。
但同一天出现了本报告历史上最难看的一个数：触及涨停 69 → 138 家（翻倍），封住 69 家，失败 69 家，回封只有 1 只。 换句话说，今天不是"封得有质量"，是"冲的人突然多了一倍、而其中一半封不住"。 修复发生在「位置」上（首板 61 只 = 88.4%），没发生在「高度」上（连板 12 → 8 只、4 板层归零、昨日 4 板有一只直接跌停）。 → 「广度扩张 + 承接力恶化」同时为真，这是本轮第一次以这种组合出现。

① 先看上一交易日（10/27）是什么日子。10/27 是缩量续跌 + 跌停潮：涨停 41 家、跌停 21 家（封死率 75.0%）、 两市成交 16088 → 14610 亿（-9.2%），11 个指数全部收绿（上证 -1.33% / 创业板 -3.41% / 科创50 -4.81% / 国证2000 -3.20%）。 今日是对那根阴线的总量修复：涨停几乎回到 10-26 的水平（54 → 69），跌停从 21 家砍到 3 家，创业板从 -3.41% 直接翻到 +3.40%。

② 量价：11 个指数全部收红 + 全部放量，这次是"真增量"，但增量全落在弹性端。 成交额环比 11/11 为正（8.6% ~ 18.5%），收盘 11/11 收红 —— 量价同向，唯一解释是增量资金进场（对照一节末的四档判据）。 但拆到风格层就露出结构：创业板 +3.40%（成交 +18.5%）、科创50 +2.45%（+18.2%）、国证2000 +2.55% 对 上证50 +0.23%（成交只 +8.6%）；行业指数层面更直白 —— 证券公司 -0.91%、中证银行 -0.62%、中证白酒 -2.43% 收盘为负。 钱不是均匀进来的：防御端（银行 / 券商 / 白酒）在被卖出，弹性端（成长 + 小微盘）在被买入 —— 风险偏好在一天内快速回升，这与 10-15「权重承接、小微盘失血」正好镜像。

③ 情绪三项：参与度↑↑、承接力↓、破坏力↓↓ —— 一个此前没出现过的组合。 参与度：触及涨停 69 → 138 家（+69 / +100%），是本报告建报以来的最高值； 承接力：封板率 59.4% → 50.0%（-9.4pct）、失败率 40.6% → 50.0%、炸板 28 → 69 只； 破坏力：跌停 21 → 3 家、触及跌停 28 → 18 家、封死率 75.0% → 16.7%（83.3% 的盘中跌停被买回）。 必须与 10-15 的「分母型假改善」严格区分：那次封板率从 60.0% 跳到 83.7%，是因为分母（触及）从 60 塌到 43、分子一只没动； 今天是分子和分母同时扩张（涨停 41→69、触及 69→138），封板率仍然掉了 9.4pct —— 这是真实的承接力不足，不是统计假象。

④ 高度：连板股 12 → 8 只（本轮最少之一），4 板层直接归零。 首板 29 → 61 只（占 88.4%，昨 70.7%）、2 板 8 → 5 只、3 板 0 → 2 只、4 板 3 → 0 只、5 板 1 → 1 只。 昨日 4 板 3 只的去向是最硬的一组证据：襄阳轴承 +9.99%、赛福天 +0.68%、多伦科技 -9.95% —— 一只晋级 5 板（襄阳轴承）、一只平收、一只直接跌停； 昨日 5 板（1 只）：上海九百 +5.11%。 塔尖只剩一根独苗：襄阳轴承（汽车零部，机器人轴承+汽车轴承+“羊”字辈，09:32 封板、封单 2.92 亿、换手 10.4%）—— 它是换手型的 5 板（换手 10.4%、成交 8.26 亿），不是一字锁仓，这一点比 10-22 的两只"一字 5 板"健康。

⑤ 主线：机器人链家数从 15 只扩到 34 只，但连板占比从 38.5% 摊薄到 23.3%。 关键词口径 34 只 = 涨停的 49.3%、成交 40.0%、封单 52.6%，散落 13 个行业； 概念榜首位「机器人概念」30 家 / 连板 7（23.3%，昨 38.5%）、「人形机器人」17 家 / 5（29.4%，昨 55.6%）。 ★ 这是"再扩散"而不是"再启动"：34 只里 30 只（88%）是今天的新面孔， 连板只有 4 只（光洋股份(3板)、东贝集团(2板)、襄阳轴承(5板)、凯众股份(2板)）。而且链条的权重票全在炸板池：东材科技（塑料，流通 380 亿，收 +8.30%）、双环传动（汽车零部，流通 341 亿，收 +8.91%）、兆威机电（电机Ⅱ，流通 203 亿，收 +5.31%）、模塑科技（汽车零部，流通 131 亿，收 +5.45%） —— 扩散是靠小票完成的，核心资产并没有封住。四日连起来看更清楚：10-23 45 只 / 27.9%（建仓）→ 10-26 27 只 / 45.5%（缩圈长高）→ 10/27 15 只 / 38.5% → 今日 34 只 / 23.3%（再扩散摊薄）。 另一条今天真正放量的线是 PCB / 覆铜板 / 元件链 11 只（昨 1 只）、成交 106.8 亿 = 涨停股成交的 26.9%； 但昨日跌停的链内标的华正新材今日只 +0.24% —— 又是"链内换人"，不是"链条修复"（同型 10-13）。

⑥ 破坏力：几乎归零，但"昨日的伤兵"并没有被救。 跌停 3 家（东财池 5 只）、跌停股合计成交 36.1 亿 = 涨停股 396.8 亿的 0.09 倍（昨 0.76 倍）。 但昨日跌停池 22 只今日：均值 -1.24%、中位 -0.47%（剔除退市整理股 002731 后均值 -1.87%）、翻红 10 只、2 只继续跌停（正裕工业 -10.03%、华瓷股份 -10.01%）、 今日涨停池 ∩ 昨日跌停池 = 0 只。 在创业板 +3.40% 的日子里，昨天跌停的票平均还在跌 —— 「跌停股不会自动修复」这一条继续成立（可枚举样本：09-29 / 09-30 / 10-09 / 10-12 / 10-13 / 10-14 / 10-15 / 10-22 / 10-23 / 今日）。

⑦ 但今天有三处"不健康"，必须写清楚，否则会被明天的数字骗到： 其一，封板率 50.0% 是本报告建报以来最低（此前最低是 10-16 的 54.6%），炸板 69 只里 流通市值 > 100 亿的 26 只、中位成交 7.81 亿 —— 大票也在冲板失败（君正股份（半导体，流通 474 亿，成交 72.75 亿，收 +18.37%）、东材科技（塑料，流通 380 亿，成交 34.70 亿，收 +8.30%）、上纬新材（塑料，流通 706 亿，成交 29.69 亿，收 +13.26%）），这不是"小票瞎炒"的问题； 其二，打板端跑输指数：昨日涨停 41 只今日中位 +2.03%，低于创业板 +3.40% 与国证2000 +2.55% —— 今天买指数比打板更赚； 其三，晋级率只有 19.5%（8/41）、新面孔 61 只占 88%，昨日首板 29 只里只有 2 只晋级。 所以这既不是"情绪反转确认"，也不是"一日游"的定论，而是一次总量修复、结构没修的普涨：家数回来了，钱进来了，但谁也没打算把票封死过夜。 明日要验证的是封板率能不能回到 60% 以上（且必须伴随触及仍在 100 家以上），而不是涨停家数能不能再涨。

按固定顺序拆三层（顺序不能颠倒）：
① 参与度（触及涨停）69 → 138 家（+69 / +100%） —— 这是本报告建报以来的最高触及值（可比样本：10-13 86 / 10-14 60 / 10-15 43 / 10-21 69 / 10-22 55 / 10-23 92 / 10-26 78 / 今日 138）。 关键：138 家 - 涨停 69 家 = 69 家被炸，占冲板总数的 50.0% —— 冲板意愿爆炸式回升，但成功率只有一半。
② 承接力（封板率）59.4% → 50.0%（-9.4pct），炸板 28 → 69 只（+41） —— 分子 41 → 69（+68%）、分母 69 → 138（+100%），两者同扩而封板率仍降 ⇒ 这是真实的承接力不足（区别于 10-15 +23.7pct / 10-21 +8.3pct 的分母型假改善）。 唯一可信的硬读数仍是炸板池：69 只、回封 1 只（1.4%）（福莱新材 +10.00%，严格按 收盘价 ≥ 涨停价 判定）。 炸板池最重的三只：君正股份（半导体，流通 474 亿，成交 72.75 亿，收 +18.37%）、东材科技（塑料，流通 380 亿，成交 34.70 亿，收 +8.30%）、上纬新材（塑料，流通 706 亿，成交 29.69 亿，收 +13.26%）。
③ 破坏力（跌停）21 → 3 家（0.1 倍）、触及跌停 28 → 18 家、封死率 75.0% → 16.7% —— 昨日的形态是"打到就封死大半"（触及 28 只、封 21 只、封死率 75.0%）；今天是"打到就有人接"（触及 18 只、封 3 只、15 只被买回）。 三项里唯一真正变好的一项，且改善幅度很大：跌停股合计成交 150.4 → 36.1 亿（0.24 倍）。
⚠ 本日形态：「参与度↑↑ + 承接力↓ + 破坏力↓↓ + 放量普涨」= 放量扩张型修复。 可枚举对照：10-09「三项同向改善 + 放量」是唯一一次干净的修复；10-08「参与度升 + 承接力崩」但当天全线放量下跌； 今日是第一次出现"参与度升 + 承接力崩 + 全线放量上涨" —— 增量是真的，但增量不是来封板的。

八、明日（10/29 周四）观察点

  • ① 封板率能不能回到 60% 以上 —— 而且必须"伴随触及仍在 100 家以上"（第一观察点）。 今日 50.0% 是建报以来最低，且是分子分母同扩下的真实读数。明日若封板率回升但触及家数掉回 70 家以内，那是又一次分母型假改善（10-15 / 10-21 各踩过一次）； 只有"触及稳在 100 家以上 + 封板率回到 60% 以上"才是承接力真的修好了。
  • ② 5 板 襄阳轴承 能不能续板，3 板两只能不能出 4 板。襄阳轴承 是换手型高度（换手 10.4%、成交 8.26 亿），质量比一字板好； 但今日 4 板层 0 只、昨日 4 板已有一只直接跌停（多伦科技 -9.95%）。若明日 3 板两只全部断板、4 板层仍空，则"高度"这一侧可以彻底判死 —— 行情只剩纯宽度游戏。
  • ③ 机器人链的 34 只家数会不会收敛。今日连板占比 23.3%（跌破 40%），且 88% 是新面孔。 分两种情形：家数降到 20 只上下而连板占比回到 40% 以上 = 缩圈再启动（10-26 走过的路，可持续）； 家数维持 30 只以上、连板占比继续降 = 摊薄延续，链条会退化成"每天换一批票涨停"的高换手赌场。
