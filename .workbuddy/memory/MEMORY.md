## 工程红线（最易反复踩的几条）

- **涨停链权威脚本只在 skill 内**。项目根 `scripts/zt_fetch.py`/`zt_analyze.py` 已改 `runpy` 转发（曾是硬编码副本，**误用静默写错日期不报错**）。自检：抓取首行必须打印 `== 复盘 {D0} 对比 {D1} ==`。
- **两段式**：抓取落盘 `out/*.json` → 分析/出报告；**「全部成功才覆盖落盘」**（写 `.tmp` 再 `os.replace`）；网络脚本绕过代理。
- **幂等比对只比 4 个核心键**：`D0`/`D1`/`today_zt_quotes`/`yesterday_zt_today`；排除 `generated_at`/`dates`/`indexes`/`index_hist`。当日成交额取 `indexes[sym].amount_wan`，**禁用 `index_hist[code].rows[-1]`**（静默回退一天）。
- **排序 tie-break 必须完整**：`sorted(set(...))` 受 str 哈希随机化影响 → 补 `(计数, -今值, -昨值, 名称)`。
- **同一文件的多个 Edit 不要并行提交**（实测 4 个只生效 1 个）；批量用「一次性补丁 + `assert a in s`」。Git Bash 下 grep/sed 处理 UTF-8 中文常失效 → 用 Read 或 python。
- **依赖归属**：`pandas/numpy` 在 managed venv；**`playwright` 只在系统 python 3.11**。
- **校验 GitHub Pages：curl 必须加 `--ssl-no-revoke`**（本机 schannel `(35) 0x80092013` = CRL 不可达 → `http_code=000`，极易误判 404）。超时 ≥120s；**标题/内容不符先重取一次**（CDN 旧边缘节点）；**推送后立刻 404 属构建队列常态，轮询 60~90s**。
- **当日情绪字段**：`senti[D0]["yest"]` 是「前一交易日」统计（=D1 值）。当日触及涨停/触及跌停/封死率取 `B["dates"][D0]["ths_zt"]["total"]["today"]["history_num"]`；`limit_down_count` 与 `total` 平级。自检：触及涨停 ≥ 涨停家数。
- **三日序列表「前日 D2」的跌停/触及跌停取 `A1(yesterday)` 而非 `A0(yesterday)`**（后者是 D1 值，曾把 10-21 触及跌停渲染成 53，实为 5）。自检：D2 列 ≠ D1 列。

- **同名 key 的残留赋值会静默覆盖正确值** → 改生成脚本后必须重新截图核对关键数字。
- `.workbuddy/` 虽在 `.gitignore` 内但**已跟踪**；`git add` 会被 ignore 拒绝，**必须 `git add -f`**（不加 -f 静默失败）。**`pull --rebase` 要求工作区干净** → 顺序 **commit → pull --rebase → push**。
- 同花顺板块指数 `bk_885xxx` 日期为 `YYYYMMDD`（计算前归一化）；早期 `ths_concept_all.json` 的 `name` 是双重转义字面量，须 `unicode_escape` 还原。

## 报告规范（红线 + 版式要点）

- 浅底深字、结论先行（首屏 lead + KPI 卡）、ECharts 5、**红涨绿跌**。
- **正文数字一律占位符注入，禁止手写**；收尾 `re.findall(r"__[A-Z_0-9]+__", html)` 查残留。**不要用 f-string 生成含 CSS/JS 的 HTML**。
- ★**跨日对比数字（「上一交易日是 X」）是全文唯一无法自证的一类，必须从 `zt_stats_{D1}.json` 现算**（曾编出 +9.96%，实为 -1.93%）；「连续第 N 个交易日」改用**可枚举日期清单**。
- ★**手写数字必须回表现算**：①"N 只散落 M 个行业" 的 M 用 `len({hybk})`；②"领跌/领涨"按绝对值重排；③"谁来自谁"回梯队表逐只核。
- ECharts 横向条形图**类目 >25** 时容器高 ≈ 类目数×21px 且 `axisLabel:{interval:0}`（**须写在对象里**）。类目轴**首项在底部** → **排名类数组传升序**。**直方图/柱图 data 不能传 `[值, 颜色]`**（图会空白），用 `vals`+`colors` 在 JS 映射。双 Y 轴图例 `top:3,left:'center'`、`grid.top≥52`。
- **ECharts 本地托管 + CDN 兜底**（`assets/echarts.min.js`）；截图 canvas=0 先怀疑 CDN。
- **三列对比表「增量列」整型分支会双符号**（`++20`）：整型用 `"{:d}"`、符号交前缀；生成后 `grep -o '++[0-9]'` 须为空。**占位符自带符号时前缀勿再补 `+`**。**正文裸写 `<` 必须 `&lt;`**。**每张表都要 `<table>` 包裹**（漏写渲染成连排文字，长报告里极难发现）。
- **行业迁移表排序须含变化幅度权重**：`-((hy0+hy1)+abs(hy0-hy1)*2)`；**标题提到的行业必须在表里真出现**。
- **模板与脚本分离**（`zt_report_{D0}.py` + `_report_tpl_{D0}.html`）；**复制模板后先跑一次再改文案**。**模板里 `__HY_XX__` 是「昨日」、`__HY_XX0__` 才是「今日」**（`hy0`=今日）→ 写「A→B」极易写反，改后 grep 渲染结果逐个核对。
- 交付前 `_check_js.py` + `_shot.py`/`_shot_el.py`（系统 3.11）。`_check_js.py` 在 managed 环境常报 `FileNotFoundError` → 绝对路径 node 手动 `--check`；**`node --check` 不支持 `<(...)`**，须先落盘。
- **概念板块榜「其中连板」与东财 `lbc` 是两套口径**：前者=连续/断续上榜（含断板重封），后者=当日连续连板数。同簇可能报 4 与 2 → **两套都给并声明差异**。

## 涨停复盘方法论

**情绪四指标分工**：`涨停+炸板`（触及涨停）=参与度/意愿；封板率与回封数=承接力；跌停家数与封死率=破坏力；成交额=**唯一裁判**。
**判定顺序固定**：触及数看意愿 → 封板率/回封看承接 → 跌停封死率看破坏力。只看涨停家数必然误判。

### 量能与价格
- **家数增+量能减 = 存量向低位扩散**；**家数减+量能增 = 增量是配置盘、打板游资在退**。
- **全线放量+全线下跌 = 抛压**：总量与价格**同向**放大才算增量入场。成交额环比只反映换手，**不区分买卖方向**。
- **「成交额环比镜像反转」是最强的次日复核工具**：某方向放量在次日缩幅最大 → 昨日放量实为场内搬家。
- **「全线放量」要拆到风格层**：环比全正但振幅全在 ±0.5% → 上证50 放量收跌 + 国证2000 放量收涨 = **高低切换**。
- **放量前三名恰好是跌幅最小的三个、放量最小三个恰好是跌得最多的三个** → 权重承接、小微盘失血。**「缩量跌是没人接，放量跌是有人在接盘出货」**。

### 情绪形态分类（先分类再下结论）
①承接力退潮（参与度平、封板率降、炸板多且 0 回封）②收缩式锁仓（参与度↓但封板率↑、缩量；**否决条件=触及涨停下滑**；三闭合证据：涨停股合计成交、单只中位成交、封单中位）③分歧 ④高位分歧（参与度↑、封板率崩）⑤三项同向修复 ⑥广度退潮型缩圈（参与度小降+承接力降+破坏力升，**但钱没走、全挤进一条线**）⑦广度回补型再平衡（三项同向改善，但最高板塌陷、首板占比升到 85%）。
⑧ **深 V / 先杀后收**：触及跌停 **≫** 封死数（`open_num` 直给"被买回"数）+ 封板时间后移（午后占比 65%）+ 11 指数**全部收于开盘价上方**且成交额环比全正 → 恐慌被承接；反之「打到就封死」（封死率 92.5%）或「全线放量+全线收绿」= 派发。
> **缩圈 vs 退潮**：看退出来的钱去哪了——某主线连板占比同步抬升（30%→69%）=**缩圈**；所有方向连板占比一起降=**退潮**。
> **「情绪修复」与「高度修复」是两件事，必须分开报**。配套信号：**首板组中位反超连板组** = 市场不再为"高度"付费、改为为"位置"付费。

### 主线真空的量化判据
- 只用一个比值：**概念板块榜 `continuous_plate_num ÷ limit_up_num`**。前七名最高连板占比 **<40%** 且前七名全是泛标签 → **当日不存在主线**。
- 必配套**榜首板块行业离散度检查**：「乡村振兴」14 家散落 13 行业 → 伪聚类须正文显式剔除（同型：电力/绿电、地产/国资重组）。
- **家数与连板占比背离时以连板占比为准**（家数回升可能只是标签扩散）。

### 承接力 / 破坏力 / 质量
- **承接力看「炸板回封只数/占比 + 炸板池市值结构」**。**回封判定铁律：收盘价 ≥ 涨停价（`p >= ztp`），禁用涨幅阈值**（用 9.8% 会把 20cm 误判）。**连续零回封是硬信号**。
- **「封板率」必须与「涨停家数绝对值」并排读**：分母（触及涨停）塌陷可造出 +23.7pct 的**假改善**（分子一只没变）。
- **破坏力量纲 = 跌停股合计成交 ÷ 涨停股合计成交**（区间 0.13~3.3 倍）。跌停股**合计成交额**比家数更灵敏。
- **判跌停池去板块化**：行业离散度 + 成交额。集中且成交额远超涨停股=板块性杀跌；分散且缩量=结束。**跌停池中大盘云集 = 机构在有流动性的大票上减持**。
- **首板组 vs 连板组中位溢价对比 = 最灵敏的情绪拐点探针**，每股必算。
- **跌停潮次日「家数回来了」≠「同一批股票回来了」**：必做「今日涨停池 ∩ 前日跌停池」代码交集，算池内均值/中位/反包只数（历次几乎全为 0）。
- **「收在涨停价」≠ 被计入家数**：收盘价=涨停价但两源都不收录、只进东财炸板池 → 家数取两源汇总、单列披露、计入回封。

### 主线归因
- **高行业离散度 ≠ 伪聚类**：判据只适用于**泛标签**。机器人链 45 只散落 19 行业，但全部同源叙事、吸走涨停股成交 63.9% → 产业链集群。判别式：`叙事同源 && 成交占比>40%` → 集群；否则剔除。仍须同时报连板占比（27.9%<40% = 宽度型主线/建仓期）。
- **行业家数持平 ≠ 行业延续**：持平时**必须算代码集合交集**（轮换率）。题材市里东财行业标签分散，最大集群常 <12%。
- **`reason_type` 关键词聚类会造伪主线** → **必须同时给「其中连板数」**。分散个股同时涨停且全首板 = 没有主线。
- **主线判定优先看 `ths_block` 概念板块榜**（比行业标签/关键词聚类少歧义）。
- **判「主线是否长高」只看 `continuous_plate_num / limit_up_num`**（20家/6连板=30% 是建仓第一天 → 16家/11连板=69% 是接力成立）。
- **「2 板梯队里有多少属于该主线」是最硬的接棒证据**（14 只中 11 只=79%）；证伪信号是**同源姊妹簇同日熄火**。
- **区域题材与「某字辈」= 主线真空信号**（横跨不相关行业、或同字辈 100% ≥2 板）。读作"没有主线"，**不是"新主线"**。
- **一字/T字锁仓型高标「开板即跌停」是高概率路径** → 高度可能是负资产。
- **同一方向可反复发作**：某链杀过不等于结束，看是否换到更龙头的大市值标的。**PCB/元件链已三轮发作零接棒**，属资金抱团孤岛。
- **长假前后的题材补涨次日兑现概率很高**，不要写成"新主线的开始"。**跨长假的基期必须显式声明**。

## 自建等权指数 / 板块复盘

- 脚本链：`pcb_fetch.py` → `pcb_analyze.py`/`pcb_extra.py` → `pcb_report.py`。
- **致命坑**：`cur *= (1+avg_ret(d))` 后再 `vals[base_d]=100` 会把**基期当日涨幅重复计入**。正确：遇基期日 `vals[base_d]=100.0; continue`；**先断言「首日收益为 0」**。最大回撤须记录当时的峰值日（`pk_at`）。
- 四件套：①区间涨幅+区间最高/最低 ②日成交额与指数的**背离**（缩量新高=重要信号）③全板块同向日 & 单日 |涨跌|≥5% 异动计数（区分 β vs Alpha）④「前期跌幅×本期涨幅」散点+回归斜率。**显式声明等权口径与市值加权指数不可比**。
- **形态分组（反包/反抽/收复）必须控制前日跌幅再看市值**：大跌日小市值本来跌得少、反包门槛天然更低。
- **热度与收益只在极端档成立**：极热（提及 ≥30 次）标的全跌、中间档无区分度 → 写"极端热度=拥挤度信号"。

## 样本口径铁律

- **1991-1992 上证处于无涨跌停/T+0 极端期**，月度统计起点取 1997-01 或 2000-01。小样本+极端值必看**中位数**。
- **双基准分解（剥离跳空）**：同给 `close(T+N)/close(T-1)`（含跳空）与 `close(T+N)/close(T+1)`（剔除首日），差额=首日贡献。国庆节后 5 日首日贡献 ≈85%。
- **用「环境档」替代「日历标签」**：按当年 1-8 月累计涨幅切分（强势 >+10%/震荡 ±10%/弱势 <-10%），10 月胜率随档位单调下降。
- **区分一手来源 vs 媒体转述**，关键数字带「来源+时点」；严禁把自媒体/AI 生成内容当事实。消息面归因三段式：事实层 / 事件催化 / 归因说明（方向矛盾时写出"市场选了哪一条"，不做方向判断）。
