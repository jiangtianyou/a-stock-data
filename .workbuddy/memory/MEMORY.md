## 数据源（重要经验）

### 已失效 / 有限流
- 东财 `push2his.eastmoney.com`（历史 K 线 `kline/get`）：**批量请求后会被限流**，表现为 ConnectionError、连接被 RST，即时失败（0.06s），需等待解封。数字前缀镜像（1./7./82.push2his）同样被拒。
- 东财 `push2.eastmoney.com`（clist 板块列表）：连续分页会被限流；`push2delay.eastmoney.com` 可用但仅提供延迟行情，**不返回历史 K 线**（返回 200 但 0 根）。

### 可用（中证指数官网）— 唯一能取「全收益指数」的通道
- **日线（价格 + 全收益）**：
  `https://www.csindex.com.cn/csindex-home/perf/index-perf?indexCode={code}&startDate=YYYYMMDD&endDate=YYYYMMDD`
  - 返回 `{code,msg,data:[{tradeDate,open,high,low,close,...}]}`；一次可取全历史（5273 条 / 0.4s），数据自 2004-12-31 起
  - **价格指数有 open；全收益指数只返回 close（无 open）** —— 做隔夜跳空分解只能用价格指数
  - **限流**：连续请求后返回 403，或返回 200 + 空 data；请求间隔 2s + 失败退避 60s 重试可恢复
  - 全收益代码 = `H` + 价格代码后 5 位：000922→H00922（中证红利）、000015→H00015（上证红利）、000300→H00300、000905→H00905、000852→H00852、000821/824/825→H00821/824/825
  - 例外：红利低波 H30269（价格）→ H20269（全收益）；红利低波100 930955 → H20955
  - 深证/国证系列（399xxx）官网无数据，仍走腾讯
- **指数有效性/名称批量核验**：`https://qt.gtimg.cn/q=sh000001,sz399997,...`（GBK，`~` 分隔，第 2 字段为名称）

### 可用（同花顺，板块指数最全 —— 板块复盘的可靠通道）

  - 返回 `quotebridge_v6_line_bk_{code}_01_last({...})`，含 `name` 与 `data`（`日期,开,高,低,收,量,额;` 分号分隔）
  - 覆盖 881101~881175（约 87 个）：881121 半导体 / 881122 光学光电子 / 881124 消费电子 / 881129 通信设备 / 881130 计算机设备 / 881163 计算机应用 / 881172 电子化学品

### 补充踩坑
- 东财限流是 **IP 级、全域名同时封**（push2his / push2 / 1./7./82. 数字前缀镜像一起 RST）。被限后 `push2delay` 的 clist 仍可用，但其 **f24/f25 不是可靠涨跌幅字段**（实测与 K 线严重不符，如"元件"60日 -6.5% 而实际 +41.8%），**不可用于排序**
- 东财 clist **每页最多 100 条**，`pz>100` 会被截成 100，需翻页；`fid=f3` 排序只返回"当日涨幅前 N"，会遗漏弱势板块
- 通达信 MCP 有**调用配额**（quota），耗尽返回 `unauthorized / quota is below 10`，批量拉指数前先确认

### 可用（腾讯财经）
- **月线/日线全历史（前复权）**：
  `https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={sym},month,1990-01-01,2026-12-31,600,qfq`

- **flashdata 月线（轻量、无限流，但历史较短且日期为 6 位 YYMMDD）**：

## 脚本约定

- 抓取脚本按「先写入 out/*.json 落盘，再分析」两段式，避免长任务丢进度
- 长时抓取务必：域名轮换 + 指数退避重试 + **逐品种增量打印**（不要用 `| tail -N` 管道，会缓冲到结束才输出，看不到进度）
- 网络脚本统一 `Session.trust_env=False`（绕过代理）
- 报告：浅底深字、结论先行、ECharts（`cdn.jsdelivr.net/npm/echarts@5`）、红涨绿跌；交付前用 `node --check` 校验提取出的 JS，用 Playwright 截图做渲染自检
- **抓取脚本必须「全部成功才覆盖落盘文件」**：限流/空返回会让重跑把已抓好的数据覆盖成空（已踩坑）。另：`{it['name']:it for it in items}` 这类字典推导会因同名键互相覆盖（价格/全收益序列同名），须按类别分开存
- ECharts 瀑布图不能用 `data:[[起,止]]`，须用「透明占位 stack + 数值 stack」
- 本机 Git Bash 下 grep/sed 处理 UTF-8 中文常失效，改用 Read 工具或 python 读文件

## 结论沉淀

- **红利指数季节性**：6 月是 A 股最强负季节性 —— 7 个红利指数全为负，价格口径 -4.01%、胜率 30.9%、t≈-3.2，包揽 81 指数负季节性第 1/2 名。其中约 **1.33% 是除息机械扣减**（6+7 月占全年分红 73.5%），**评估红利真实回报必须用全收益指数**，价格指数每年 6-7 月会少算约 2.7pp。剩余弱势主因是风格轮动（6 月成长 +3.01% vs 红利 -2.80%）。正季节性（2/7/12 月）2015 年后基本消失，仅 6 月坏效应保留约 40%。
- **ECharts 双 Y 轴图的图例不要设 `right:8`**：会与右侧轴名/刻度重叠（渲染成"胜率%率"）。用 `top:3,left:'center'` 且 `grid.top≥52` 做垂直分离
- **同一文件的多个 Edit 不要在同一条消息里并行提交**：会相互覆盖（实测 4 个只生效 1 个）。批量改配置类脚本改用「一次性补丁脚本 + `assert a in s` 断言」
- **依赖归属要分清**：`pandas/numpy` 在 managed venv（`~/.workbuddy/binaries/python/envs/default`），**`playwright` 只在系统 python 3.11**（`C:/Users/Administrator/AppData/Local/Programs/Python/Python311/python.exe`）。截图自检要用系统 3.11 跑 `_shot.py`，venv 里会 ModuleNotFoundError。

## 事件窗口分析的两个可复用技巧

- **双基准分解（剥离首日跳空）**：算「节后/事件后 N 日」时同时给两套基准——`close(T+N)/close(T-1)`（含跳空）与 `close(T+N)/close(T+1)`（剔除首日）。两者差额 = 首日贡献。A股国庆节后 5 日中首日贡献 ≈85%，不带这个分解会得出「节后一周都涨」的错误印象。
- **用「环境档」替代「日历标签」**：季节性现象（红十月等）按年份切分往往不成立，按**市场状态**切分才有解释力。已验证有效的分档变量：**当年 1-8 月累计涨幅**（强势 >+10% / 震荡 -10~+10% / 弱势 <-10%）。10 月胜率随档位单调下降（88.9% / 30.8% / 28.6%）。
- 专题报告生成器命名避开并行会话占用的文件名：本次用 `oct_holiday_report.py` → `reports/国庆长假效应复盘-20260915.html`

## 板块级复盘（自建等权指数）— 以 PCB 板块 8 月复盘为模板

- 脚本链：`pcb_fetch.py` → `pcb_analyze.py`（合成指数 + 逐日/个股统计）/ `pcb_extra.py`（量能 + 分段 + 相关性）→ `pcb_report.py` → `reports/PCB板块8月以来走势复盘-20260915.html`。无官方成分股可用时的通用模板。
- **等权指数合成的致命坑**：`for d in axis: cur *= (1+avg_ret(d))` 之后再 `vals[base_d]=100`，会把**基期当日的板块涨幅重复计入一次**（本次多算 5.2%，把真实 +49.22% 放大成 +56.96%）。正确写法：遇到基期日 `vals[base_d]=100.0; continue`，不累乘当日收益。任何自建指数都要先做一次「首日收益应为 0」的断言。
- **报告正文的数字一律由数据推导 + `__占位符__` 替换，不要手写**。本次手写的总涨幅、三段涨幅、最大回撤、异动次数共 8 处在指数修正后全部失效；改成 python 变量 + `.replace()` 后一次对齐。收尾必做 `grep -c "__[A-Z_]*__"` 确认无残留占位符。
- 最大回撤要记录**回撤发生当时的峰值日**（`pk_at`），不能直接用全局 peak 日——指数持续新高时全局 peak 日会晚于最低点，输出成「09-15→08-24」这种时间倒序。
- 板块复盘四件套指标：①区间涨幅 + 区间内最高/最低（附「距高点」）②日成交额与指数的**背离**（缩量新高是重要信号）③全板块同向日（34/34 全涨/全跌）与单日 |涨跌|≥5% 的异动计数 → 反映 β 主导还是个股 Alpha ④**「前期跌幅 × 本期涨幅」散点 + 回归斜率**，用于区分「超跌反弹」与「基本面驱动」。
- 自建样本池分三层（制造 / 上游材料 / 设备）并**显式声明等权口径与商业市值加权指数不可比**；样本遗漏要写进口径说明。
