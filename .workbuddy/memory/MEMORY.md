## 脚本与工程约定

- **两段式**：先抓取落盘 `out/*.json`，再分析/出报告。长时抓取用域名轮换 + 指数退避 + **逐品种增量打印**（不要 `| tail -N`，会缓冲到结束）。网络脚本统一绕过代理（`ProxyHandler({})` / `Session.trust_env=False`）。
- **抓取脚本必须「全部成功才覆盖落盘」**（写 `.tmp` 再 `os.replace`），否则重跑会把好数据覆盖成空。
- **盘后复跑幂等比对只比四个核心键**：`D0`/`D1`/`today_zt_quotes`/`yesterday_zt_today`；排除 `generated_at`、`dates`、`indexes`（市值尾数抖动）、`index_hist`（**盘后会把当日行移出返回窗口**）。当日成交额一律取实时快照 `indexes[sym].amount_wan`，**禁止用 `index_hist[code].rows[-1]` 当当日**（会静默回退一天）。
- **排序 tie-break 必须完整**：`sorted(set(...))` 同分项受 str 哈希随机化影响 → 补 `(计数, -今值, -昨值, 名称)`。
- **同一文件的多个 Edit 不要并行提交**（实测 4 个只生效 1 个）；批量改脚本用「一次性补丁 + `assert a in s`」。Git Bash 下 grep/sed 处理 UTF-8 中文常失效 → 用 Read 工具或 python。
- **涨停链的权威脚本只在 skill 内**（`.workbuddy/skills/a-share-limit-up-review/scripts/`）。项目根 `scripts/zt_fetch.py` / `zt_analyze.py` 曾是日期硬编码的过期副本，误用会**静默写错日期且不报错**（09-30 实测）→ 已改写为 `runpy` 转发到 skill 副本。**项目根 `scripts/` 只放 `zt_report_{D0}.py` / `zt_week_*.py`。** 自检：抓取首行必须打印 `== 复盘 {D0} 对比 {D1} ==`。
- **依赖归属**：`pandas/numpy` 在 managed venv（`~/.workbuddy/binaries/python/envs/default/Scripts/python.exe`）；**`playwright` 只在系统 python 3.11**（`.../Python311/python.exe`），venv 跑 `_shot.py` 会 ModuleNotFoundError。
- **`senti[D0]["yest"]` 是「前一交易日」统计（= D1 值），不是当日**：当日/前日「触及涨停、触及跌停、封死率」一律取 `B["dates"][D0]["ths_zt"]["total"]["today"]["history_num"]`；`limit_down_count` 与 `total` 是 `ths_zt` 下**平级键**。自检：`触及涨停 ≥ 涨停家数`。
- **`zt_fetch.resolve_dates` 只取前 2 个参数** → `zt_review_{D0}.json` 只含 D0/D1；`zt_analyze.py` 三日序列仍正确（`days[0]` 用 `senti[D1]["zt_prev"]`），**不必补抓 D2**。
- 同花顺板块指数 `bk_885xxx` 日期为 **`YYYYMMDD`**（计算前须归一化）。早期 `out/ths_concept_all.json` 的 `name` 是**双重转义字面量**，中文 `in` 全失败 → 用 `chr()` 码点或 `unicode_escape` 还原。
- **同名 key 的残留赋值会静默覆盖正确值**（`K["ZBJ_FLOW20"]` 被后面 `*0` 覆盖成 0）。改生成脚本后必须重新截图核对关键数字。
- **文本语料（评论/舆情）词频统计用 SQL `SUM(col LIKE '%X%')` 一次批量算上百个关键词**，别把全量文本拉回本地分词——快、精确、可复现；JSON 字段（如 `replies_json`）用 `LIKE` 直接匹配即可。简称要合并，但须人工剔除同名误匹配。
- **热度与收益的关系只在极端档成立**（09-30 实测）：抖音评论提及 ≥30 次的标的 9 月全部下跌，但中间档无区分度（Spearman -0.032）。**不要写成"热度越高越差"的线性叙事**，应写"极端热度 = 拥挤度信号"。

## 报告规范

- 浅底深字、结论先行（首屏 lead + KPI 卡）、ECharts 5、**红涨绿跌**。
- **正文数字一律由数据推导 + `__占位符__` + `.replace()` 注入，禁止手写**；收尾 `re.findall(r"__[A-Z_0-9]+__", html)` 确认无残留。**不要用 f-string 生成含 CSS/JS 的 HTML**。
- ECharts 横向条形图**类目 >25** 时容器高 ≈ 类目数×21px 且 `axisLabel:{interval:0}`（**须写在对象里**，传纯数组会被抽稀）。类目轴**首项在底部** → 排名类数组须**先反转**再喂 `yAxis.data`。
- 双 Y 轴图图例用 `top:3,left:'center'`（**不要 `right:8`**）；`grid.top≥52`。瀑布图不能 `data:[[起,止]]`，须「透明占位 stack + 数值 stack」。
- 交付前：`_check_js.py <html>` + `_shot.py <html> <scrollY...>`（用系统 3.11）。`_check_js.py` 依赖 `node` 在 PATH，managed 环境常报 `FileNotFoundError`（**非报告问题**）→ 用绝对路径 node 手动 `--check`。
- **三列对比表「增量列」整型分支会双符号**（`"+{}".format("{:+d}")` → `++20`）：整型用 `"{:d}"`、符号交给前缀；生成后 `grep -o '++[0-9]'` 必须为空。
- **行业迁移表排序须含变化幅度权重**：只按 `-(hy0*2+hy1)` 会把「3→0 清零行业」挤出前 18 行 → 用 `-((hy0+hy1)+abs(hy0-hy1)*2)`；**标题提到的行业必须在表里真的出现**。
- **ECharts 本地托管 + CDN 兜底**：`assets/echarts.min.js` + `<script src="../assets/echarts.min.js">` + `if(typeof echarts==='undefined'){document.write(CDN)}`。起因 jsdelivr 在 Playwright 侧间歇 `ERR_CONNECTION_RESET` → `canvas=0`+`echarts is not defined` —— **「截图自检报 canvas=0」先怀疑 CDN**。
- **涨停/指数报告可复用件**：① 情绪三日序列（涨停/炸板/跌停/封板率 + 触及涨停家数）② 各指数成交额环比表（`tbl_sty` + `amt_yoy(nm)` 读 `zt_review_{D1}.json` 的 `indexes` 补全，`idx_cmp` 只覆盖 4 个指数）③ 炸板池「回封/未回封」拆分表 ④ 昨日涨停股溢价横向条形图 ⑤ 名称族群表（「华」字辈 / 新华系）⑥ 区域题材/产业链集群表 ⑦ 行业成分轮换率（代码集合交集）。

## 结论沉淀（涨停复盘方法论）

**情绪四指标分工**：`涨停+炸板`（触及涨停家数）=**参与度/意愿**；封板率与回封数=**承接力**；跌停家数与封死率=**破坏力**；成交额=**唯一裁判**。
**判定顺序固定**：先算触及数看意愿 → 再看封板率/回封看承接 → 最后看跌停封死率看破坏力。只看涨停家数必然误判。

### 量能与价格的三种关系
- **家数增 + 量能减 = 存量向低位扩散**（09-21：涨停 +24 而成交 -2.2%）→ 不是增量入场。
- **家数减 + 量能增 = 增量是配置盘、打板游资在退**（09-22：涨停 101→62 而成交 +5.1%）→ 必看各指数成交额增速结构（增量在权重/科技龙头而非小微盘）；**不能读成情绪升温**。
- **全线放量 + 全线下跌 = 抛压**（10-08：两市 +17.0%、11 指数成交额环比全为正且全收绿）→ 主动卖出增加、承接盘被动接货。**总量与价格同向放大才算增量入场，反向就是抛压。** 口径提示：成交额环比只反映换手放大，**不区分买卖方向**。
- **增量方向相反 = 调仓而非增量**（09-30）：成交只 +2.0%，增量全落在涨跌相反的两方向（科创50 +11.4% 却收 -2.51%、上证50 +11.6% 收 +0.47%），而中证500/北证50 反而缩量 → 同一笔增量资金不可能同时买权重卖成长 → 是资金从成长换进权重。**看放量方向永远要同时看它的涨跌符号。**
- **成交额环比的"镜像反转"是最强的次日复核工具**：09-22「增量是配置盘」→ 09-23 该方向缩幅最大（-33.8%/-34.0%）证伪；09-23「权重先撤」→ 09-24 上证50 +5.7%（唯一放量）。**「各指数成交额环比」是每日必看第一张表。**

### 情绪形态四分类（先分类再下结论）
①**承接力退潮**（09-23：参与度平 80→77、封板率 77.5%→66.2%、26 只炸板 0 回封）
②**收缩式锁仓**（09-24：参与度 77→61 ↓、封板率 ↑83.6%、缩量；否决条件就是触及涨停下滑 → 愿冲板的钱少了，只因无换手才封得住；三闭合证据：涨停股合计成交 -15%、单只中位 -15%、封单中位 **+13%**）
③**分歧**（09-30：参与度平 64→64、承接力小降 -6.2pct）
④**高位分歧**（10-08：参与度 64→74 ↑、封板率 81.2%→56.8% 崩 = 冲板意愿在、封不住）
判据固定顺序：触及涨停家数 → 封板率/回封只数 → 跌停家数/封死率。

### 承接力 / 破坏力 / 质量
- **承接力看「炸板回封只数/占比 + 炸板池市值结构」，不只看炸板家数**：10-08 炸板 32 只仅 1 只回封（3%）、池内中大盘云集（招商轮船 1779亿）=「有重量的资金在有重量的品种上被打回」；09-24 炸板骤降则是"只剩小票"→ 含义相反。
- **破坏力的量纲 = 跌停股合计成交 ÷ 涨停股合计成交**：09-28=3.3 倍、09-30=0.17 倍、10-08=1.62 倍。家数不极端但成交额远超涨停股 → 是大票在杀跌。**跌停股合计成交额（而非家数）对"破坏力"更灵敏。**
- **判「跌停池是否去板块化」**：看行业离散度 + 成交额。09-28 跌停 56 只中 19 只（34%）同属算力硬件链、跌停成交 756 亿 = 涨停股 3.3 倍；09-29 跌停 10 只分散 9 个行业、合计仅 74.3 亿 → 板块性杀跌结束。
- **首板组 vs 连板组的溢价对比 = 最灵敏的情绪拐点探针**：每股必算。09-23/24「首板弱/连板强」（差 3.87pct）→ 09-29 反转（首板 +3.02% > 连板 +1.32%）→ 09-30 又切回且差 10.81pct → 10-08 差 12.32pct 刷新最大。
- **跌停潮次日的「家数回来了」≠「同一批股票回来了」**（09-29）：前日跌停池 19 只算力硬件链只有 1 只反包涨停、19 只今日均值 +0.11%（剔该只 -0.44%）→ 必做「今日涨停池 ∩ 前日跌停池」代码交集，算池内均值/中位/反包只数（分方向各算）。
- **「收在涨停价」不等于被计入家数**（09-22/09-24）：瑞芯微 +10.00%、三羊马 +10.01% 收盘=涨停价但两源涨停池都不收录，只进东财炸板池 → 家数取两源汇总、单列披露、计入「回封」。

### 主线归因
- **行业家数持平 ≠ 行业延续**（09-24：东财「通用设备」6→6 但成分只留存 1 只，轮换 83%）→ 家数持平时**必须算代码集合交集**；东财行业标签在题材市里分散（09-24：51 只散在 32 个行业、最大集群仅 11.8%）。
- **`reason_type` 关键词聚类会造伪主线**（09-30）→ 聚类家数大 ≠ 主线，**必须同时看「其中连板数」**。真主线看高度（医药簇 8 家但连板 0 = 消息日打法；固态电池簇 6 家/4 家连板 = 真主线）。**被剔除的分散簇本身就是结论：分散个股同时涨停且全是首板 = 市场没有主线。**
- **区域题材与「某字辈」= 主线真空信号**：09-24 海峡两岸/福建 10 只（占涨停 20%）横跨 10 个不相关行业；09-22 12 只含"华"字标的 100% ≥2 板。**正确读法是"没有主线的信号"，不是"新主线"**；伴生现象是同批「跨界资产注入」涨停。
- **同一方向可反复发作**：算力硬件链 09-28 第一轮（27/56 家）→ 10-08 第二轮（5/13 家、成交占跌停池 70%）。「某链杀过一次」不等于结束，要看是否换到更龙头的大市值标的。
- **判「题材补涨」的兑现规律**：09-29 反抽 → 09-30 证伪；09-30 医药（8 家）→ 10-08 只剩 2 家。**长假前后的题材补涨，次日兑现概率很高**，不要写成"新主线的开始"。
- **跨长假的基期必须显式声明**（10-08 对比 09-30 隔 7 个自然日）："昨日涨停股今日表现"不能当常规隔日溢价读。

## 自建等权指数 / 板块复盘（模板见 PCB 8 月复盘）

- 脚本链：`pcb_fetch.py` → `pcb_analyze.py`/`pcb_extra.py` → `pcb_report.py`。
- **致命坑**：`cur *= (1+avg_ret(d))` 后再 `vals[base_d]=100` 会把**基期当日涨幅重复计入**。正确：遇基期日 `vals[base_d]=100.0; continue`。**任何自建指数先断言「首日收益为 0」**。
- 最大回撤须记录**回撤当时的峰值日**（`pk_at`），不能用全局 peak 日。
- 四件套：①区间涨幅 + 区间最高/最低（附距高点）②日成交额与指数的**背离**（缩量新高是重要信号）③全板块同向日 & 单日 |涨跌|≥5% 异动计数（区分 β vs Alpha）④「前期跌幅 × 本期涨幅」散点 + 回归斜率。
- 样本池分层并**显式声明等权口径与市值加权指数不可比**。

## 样本口径铁律（季节性 / 事件研究）

- **1991-1992 上证处于无涨跌停/T+0 极端期**（1 月均值 28%、std 173%），月度统计起点取 **1997-01 或 2000-01**。
- 小样本 + 极端值必看**中位数**。
- **双基准分解（剥离跳空）**：同时给 `close(T+N)/close(T-1)`（含跳空）与 `close(T+N)/close(T+1)`（剔除首日），差额 = 首日贡献。国庆节后 5 日首日贡献 ≈85%。
- **用「环境档」替代「日历标签」**：按**当年 1-8 月累计涨幅**切分（强势 >+10%/震荡 ±10%/弱势 <-10%），10 月胜率随档位单调下降（88.9%/30.8%/28.6%）。
