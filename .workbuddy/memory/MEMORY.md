## 工程约定

- **两段式**：抓取落盘 `out/*.json` → 分析/出报告。长时抓取用域名轮换 + 指数退避 + **逐品种增量打印**（勿 `| tail -N`，会缓冲）。网络脚本统一绕过代理（`ProxyHandler({})` / `trust_env=False`）。
- **抓取脚本「全部成功才覆盖落盘」**（写 `.tmp` 再 `os.replace`）。
- **盘后复跑幂等比对只比 4 个核心键**：`D0`/`D1`/`today_zt_quotes`/`yesterday_zt_today`；排除 `generated_at`/`dates`/`indexes`（市值尾数抖动）/`index_hist`（盘后把当日行移出返回窗口）。当日成交额取 `indexes[sym].amount_wan`，**禁止用 `index_hist[code].rows[-1]`**（会静默回退一天）。
- **排序 tie-break 必须完整**：`sorted(set(...))` 受 str 哈希随机化影响 → 补 `(计数, -今值, -昨值, 名称)`。
- **同一文件的多个 Edit 不要并行提交**（实测 4 个只生效 1 个）；批量改用「一次性补丁 + `assert a in s`」。Git Bash 下 grep/sed 处理 UTF-8 中文常失效 → 用 Read 工具或 python。
- **涨停链权威脚本只在 skill 内**（`.workbuddy/skills/a-share-limit-up-review/scripts/`）。项目根 `scripts/zt_fetch.py`/`zt_analyze.py` 曾是硬编码过期副本（**误用会静默写错日期不报错**）→ 已改 `runpy` 转发。项目根 `scripts/` 只放 `zt_report_{D0}.py`/`zt_week_*.py`。自检：抓取首行必须打印 `== 复盘 {D0} 对比 {D1} ==`。
- **依赖归属**：`pandas/numpy` 在 managed venv；**`playwright` 只在系统 python 3.11**（venv 跑 `_shot.py` 会 ModuleNotFoundError）。
- **校验 GitHub Pages：curl 必须加 `--ssl-no-revoke`**（本机 schannel `(35) 0x80092013`=CRL 不可达 → `http_code=000`、不落盘，极易误判 404）。超时 ≥120s。**内容/标题不符先重取一次**（CDN 旧边缘节点）。
- **`senti[D0]["yest"]` 是「前一交易日」统计（=D1 值）**：当日触及涨停/触及跌停/封死率一律取 `B["dates"][D0]["ths_zt"]["total"]["today"]["history_num"]`；`limit_down_count` 与 `total` 是 `ths_zt` 下平级键。自检：触及涨停 ≥ 涨停家数。
- **`zt_fetch.resolve_dates` 只取前 2 个参数** → review 文件只含 D0/D1；`zt_analyze.py` 三日序列仍正确（`days[0]` 用 `senti[D1]["zt_prev"]`），不必补抓 D2。
- 同花顺板块指数 `bk_885xxx` 日期为 `YYYYMMDD`（计算前归一化）。早期 `out/ths_concept_all.json` 的 `name` 是双重转义字面量，中文 `in` 全失败 → 用 `chr()` 或 `unicode_escape` 还原。
- **同名 key 的残留赋值会静默覆盖正确值**（`K["ZBJ_FLOW20"]` 被后面 `*0` 覆盖）。改生成脚本后必须重新截图核对关键数字。
- **文本语料词频统计用 SQL `SUM(col LIKE '%X%')` 批量算**，别拉全量回本地分词。简称须合并并剔除同名误匹配。
- 腾讯 `qt.gtimg.cn` 快照：**f44=流通市值、f45=总市值（亿元）**，f3=现价、f30=时间戳（前8位 YYYYMMDD），响应 **GBK**。`statistics` 模块无 `log10`，须 `import math`。
- Mann-Whitney U / Spearman 可标准库手算（秩次+z 近似），`|z|>1.96 ≈ p<0.05`。

## 报告规范

- 浅底深字、结论先行（首屏 lead + KPI 卡）、ECharts 5、**红涨绿跌**。
- **正文数字一律数据推导 + `__占位符__` + `.replace()` 注入，禁止手写**；收尾 `re.findall(r"__[A-Z_0-9]+__", html)` 查残留。**不要用 f-string 生成含 CSS/JS 的 HTML**。占位符值自带符号时前缀勿再补 `+`（否则 `++11.6%`）。
- ECharts 横向条形图**类目 >25** 时容器高 ≈ 类目数×21px 且 `axisLabel:{interval:0}`（**须写在对象里**，传纯数组会被抽稀）。类目轴**首项在底部** → **排名类数组传升序**。双 Y 轴图例 `top:3,left:'center'`（不要 `right:8`），`grid.top≥52`。瀑布图须「透明占位 stack + 数值 stack」，不能 `data:[[起,止]]`。
- 交付前：`_check_js.py <html>` + `_shot.py <html> <scrollY...>`（系统 3.11）。`_check_js.py` 依赖 node 在 PATH，managed 环境常报 `FileNotFoundError`（非报告问题）→ 绝对路径 node 手动 `--check`；**`node --check` 不支持进程替换 `<(...)`**，须先落盘。
- **三列对比表「增量列」整型分支会双符号**（`"+{}".format("{:+d}")`→`++20`）：整型用 `"{:d}"`、符号交前缀；生成后 `grep -o '++[0-9]'` 须为空。
- **行业迁移表排序须含变化幅度权重**：用 `-((hy0+hy1)+abs(hy0-hy1)*2)`（只按 `-(hy0*2+hy1)` 会把「3→0 清零行业」挤出前 18 行）；**标题提到的行业必须在表里真出现**。
- **ECharts 本地托管 + CDN 兜底**：`assets/echarts.min.js` + `if(typeof echarts==='undefined'){document.write(CDN)}`。截图自检报 canvas=0 先怀疑 CDN（jsdelivr 间歇 `ERR_CONNECTION_RESET`）。
- 报告统一**模板与脚本分离**（`zt_report_{D0}.py` + `_report_tpl_{D0}.html`）；复制模板后**先跑一次再改文案**。
- **模板里 `__HY_XX__` 是「昨日」、`__HY_XX0__` 才是「今日」**（`hy0`=今日、`hy1`=昨日，占位符命名按旧版）→ 写「A→B」方向极易写反，改后必须 grep 渲染结果逐个核对。
- **涨停/指数报告可复用件**：①情绪三日序列 ②各指数成交额环比表（`tbl_sty`+`amt_yoy(nm)` 读 `zt_review_{D1}.json` 的 `indexes` 补全，`idx_cmp` 只覆盖 4 个指数）③炸板池回封/未回封拆分表 ④昨日涨停股溢价横向条形图 ⑤名称族群表 ⑥区域题材/产业链集群表 ⑦行业成分轮换率（代码集合交集）。
- **概念板块榜的「其中连板」与东财 `lbc` 是两套口径**（10-14）：`continuous_plate_num` = 连续/断续上榜（含断板后重新封回的高标），`lbc` = 当日连续连板数。同簇可能报 4 与 2 → **两套都给并声明差异**；判「主线是否长高」用前者，判「今日封板梯队」用后者。
- **手写数字必须回表现算**（10-14 连踩三处）：①"N 只散落 M 个行业" 的 M 要 `len({hybk})` 现算；②"领跌/领涨"排序按绝对值重排后再写；③"谁来自谁"的归属句回梯队表逐只核。**每处手写数字出稿前回表核对一次。**

## 涨停复盘方法论

**情绪四指标分工**：`涨停+炸板`（触及涨停家数）=参与度/意愿；封板率与回封数=承接力；跌停家数与封死率=破坏力；成交额=**唯一裁判**。
**判定顺序固定**：触及数看意愿 → 封板率/回封看承接 → 跌停封死率看破坏力。只看涨停家数必然误判。

### 量能与价格
- **家数增+量能减 = 存量向低位扩散**，非增量入场；**家数减+量能增 = 增量是配置盘、打板游资在退**，不能读成情绪升温。
- **全线放量+全线下跌 = 抛压**：总量与价格**同向**放大才算增量入场。成交额环比只反映换手，**不区分买卖方向**。
- **增量方向相反 = 调仓而非增量**：看放量方向永远同时看它的涨跌符号。
- **「成交额环比镜像反转」是最强的次日复核工具**：某方向放量在次日缩幅最大 → 昨日放量实为场内搬家。
- **「全线放量」要拆到风格层**（10-13）：11 指数环比全正但振幅全在 ±0.5% → 拆开是「上证50 +16.0% 收 -0.43%（权重派发）+ 国证2000 +9.2% 收 +0.29%（题材吸金）」= **高低切换，非增量入场**。

### 情绪形态分类（先分类再下结论）
①承接力退潮（参与度平、封板率降、炸板多且 0 回封）②收缩式锁仓（参与度↓但封板率↑、缩量；**否决条件=触及涨停下滑**；三闭合证据：涨停股合计成交、单只中位成交、封单中位）③分歧（参与度平、承接力小降）④高位分歧（参与度↑、封板率崩）⑤三项同向修复（10-09 本轮首次）⑥广度退潮型缩圈（参与度小降+承接力降+破坏力升，**但钱没走、全挤进一条线**；10-12）⑦广度回补型再平衡（10-13：三项同向改善，但**最高板从 10 板塌到 3 板**、首板占比升到 85%）。
> **缩圈 vs 退潮判别**：看退出来的钱去哪了——某主线连板占比同步抬升（30%→69%）=**缩圈**（结构性、可延续）；所有方向连板占比一起降=**退潮**。
> **「情绪修复」与「高度修复」是两件事，必须分开报**；只看参与度/封板率/跌停数会把"塔尖被削平"写成"情绪回暖"。配套信号：**首板组中位反超连板组**（10-13 首次翻正 +0.32pct）= 市场不再为"高度"付费、改为为"位置"付费。

### 主线真空的量化判据
- 只用一个比值：**概念板块榜 `continuous_plate_num ÷ limit_up_num`**。前七名最高连板占比 **<40%** 且前七名全是泛标签 → **当日不存在主线**。
- 必配套**榜首板块行业离散度检查**：10-13「乡村振兴」14 家散落 13 个行业 → 伪聚类，须正文显式剔除（同型：09-30 电力/绿电、10-09 地产/国资重组）。
- **「涨停家数回升」可能只是标签扩散**：家数与连板占比背离时以连板占比为准。

### 承接力 / 破坏力 / 质量
- **承接力看「炸板回封只数/占比 + 炸板池市值结构」**，不只看炸板家数：炸板多但仅个别回封、池内中大盘云集 =「有重量的资金在有重量的品种上被打回」；炸板骤降若是"只剩小票"则含义相反。
  - **回封判定铁律：用「收盘价 ≥ 涨停价」（东财 `p >= ztp`），禁止用涨幅阈值**（10-13 用 `zdp>=9.8` 把 3 只 20cm 标的误判为回封，真实回封 0 只）。
- **破坏力量纲 = 跌停股合计成交 ÷ 涨停股合计成交**（09-28=3.3 / 09-30=0.17 / 10-08=1.62 / 10-09=0.22 倍）。跌停股**合计成交额**比家数更灵敏。
- **判跌停池是否去板块化**：行业离散度 + 成交额。集中且成交额远超涨停股=板块性杀跌；分散多行业且合计缩量=结束。
- **首板组 vs 连板组溢价对比 = 最灵敏的情绪拐点探针**，每股必算。
- **跌停潮次日「家数回来了」≠「同一批股票回来了」**：必做「今日涨停池 ∩ 前日跌停池」代码交集，算池内均值/中位/反包只数。
- **「收在涨停价」不等于被计入家数**：收盘价=涨停价但两源涨停池都不收录、只进东财炸板池（创业板/科创板阈值 19.8%）→ 家数取两源汇总、单列披露、计入回封。

### 主线归因
- **行业家数持平 ≠ 行业延续**：持平时**必须算代码集合交集**（轮换率）。东财行业标签在题材市里分散，最大集群常 <12%。
- **`reason_type` 关键词聚类会造伪主线** → 聚类家数大 ≠ 主线，**必须同时看「其中连板数」**。**被剔除的分散簇本身就是结论：分散个股同时涨停且全是首板 = 市场没有主线。**
- **主线判定优先看 `ths_block` 概念板块榜**（比行业标签/关键词聚类更少歧义），同样必须给「其中连板数」。
- **判「主线是否长高」只看 `continuous_plate_num / limit_up_num`**（10-09 AI应用 20家/6连板=30% 是集体建仓第一天 → 10-12 文化传媒概念 16家/11连板=69% 是接力成立）。比涨停家数本身有用得多。
- **「2 板梯队里有多少属于该主线」是最硬的接棒证据**（10-12：2 板 14 只中 11 只=79% 系传媒/AI）；证伪信号是**同源姊妹簇同日熄火**（AI安全/信创 7→2 家）。
- **区域题材与「某字辈」= 主线真空信号**（横跨多个不相关行业、或同字辈 100% ≥2 板）。正确读法是"没有主线的信号"，**不是"新主线"**；伴生现象是同批「跨界资产注入」涨停。
- **同一方向可反复发作**：某链杀过一次不等于结束，看是否换到更龙头的大市值标的。
- **长假前后的题材补涨，次日兑现概率很高**，不要写成"新主线的开始"。**跨长假的基期必须显式声明**。

## 自建等权指数 / 板块复盘（模板见 PCB 8 月复盘）

- 脚本链：`pcb_fetch.py` → `pcb_analyze.py`/`pcb_extra.py` → `pcb_report.py`。
- **致命坑**：`cur *= (1+avg_ret(d))` 后再 `vals[base_d]=100` 会把**基期当日涨幅重复计入**。正确：遇基期日 `vals[base_d]=100.0; continue`。**任何自建指数先断言「首日收益为 0」**。
- 最大回撤须记录**回撤当时的峰值日**（`pk_at`），不能用全局 peak 日。
- 四件套：①区间涨幅+区间最高/最低（附距高点）②日成交额与指数的**背离**（缩量新高是重要信号）③全板块同向日 & 单日 |涨跌|≥5% 异动计数（区分 β vs Alpha）④「前期跌幅×本期涨幅」散点+回归斜率。样本池分层并**显式声明等权口径与市值加权指数不可比**。
- **形态类分组（反包/反抽/收复）必须控制前日跌幅再看市值**：大跌日小市值本来跌得少、反包门槛天然更低，不控制变量会把「跌幅小」误读成「资金偏好小市值」。
- **热度与收益只在极端档成立**：极热（提及 ≥30 次）标的全跌，中间档无区分度。应写"极端热度=拥挤度信号"，不要写成线性叙事。

## 样本口径铁律

- **1991-1992 上证处于无涨跌停/T+0 极端期**，月度统计起点取 1997-01 或 2000-01。小样本+极端值必看**中位数**。
- **双基准分解（剥离跳空）**：同给 `close(T+N)/close(T-1)`（含跳空）与 `close(T+N)/close(T+1)`（剔除首日），差额=首日贡献。国庆节后 5 日首日贡献 ≈85%。
- **用「环境档」替代「日历标签」**：按当年 1-8 月累计涨幅切分（强势 >+10%/震荡 ±10%/弱势 <-10%），10 月胜率随档位单调下降（88.9%/30.8%/28.6%）。
- **区分一手来源 vs 媒体转述**，关键数字带「来源+时点」；严禁把自媒体/AI 生成内容当事实。
