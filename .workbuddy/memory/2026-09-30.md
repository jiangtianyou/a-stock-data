  1. **不要人工数频次**——用 SQL `SUM(main_text LIKE '%X%')` 一次批量统计上百个关键词，
     主评论 + 回复文本（`replies_json` 是 JSON 但 `LIKE` 直接可匹配，无需展开）。比拉全量文本回来分词快得多、也精确。
