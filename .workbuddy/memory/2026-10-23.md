## 工程修正
1. 新增 pitfall 41：三日序列表 D2 列的跌停/触及跌停须取 **D1 文件**的 `yesterday`（D0 文件的 `yesterday` 是 D1）；

2. 新增 pitfall 42：高行业离散度不能单独判伪聚类，须加判「叙事同源 + 成交占比」。
3. 新增 pitfall 43：「深 V / 先杀后收」三件套量化判据。
4. 报告模板补了三处遗漏的 `<table>` 包裹（TBL_IDX / TBL_CONC / TBL_HY），否则渲染成连排文字。
5. `JS_REL` 直方图 data 不能用 `[值, 颜色]` 数组（ECharts 会把数组当数值 → 图空白），改为 `vals` + `colors` 双数组。
6. 模板占位符自带符号时前缀勿再写 `+`（`++1.21%`）；正文 `<40%` 必须写 `&lt;`（否则被当标签吞掉半句）。
